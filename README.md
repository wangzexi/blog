# Zexi's Blog

> 有价值的未必是我的结论，而是它们带给你思考的扰动。
>
> 每篇文章的 `README.md`，是我预先整理好的一条线性阅读路径，是一份默认视角下的"预制菜"。
>
> 文章文件夹则是一份完整的上下文包：`refs/` 保存原始材料和写作过程，`assets/` 保存正文引用的图片等资源。
>
> GitHub 会完整保留文章文件夹中的 `README.md`、`refs/` 和 `assets/`；zexi.me 展示其中的 `README.md`，并发布页面所需的 `assets/`。
>
> 推荐你用 AI 工具打开本文件夹，先读主线，再带着被启发出的问题，让 AI 基于整个文件夹为你"现炒"。通常会比"帮我总结全文"更有价值。
>
> `git clone git@github.com:wangzexi/blog.git`
